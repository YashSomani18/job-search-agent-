# Email Preview - What You'll Receive

## Email Subject
```
Job Search Results - 87 Jobs Found (2025-10-31)
```

## Email Format (HTML Email)

The email will be beautifully formatted with:

### Header Section
- Blue header with title: "🎯 Job Search Results"
- Shows total number of jobs found
- Search date and time
- Keywords used
- Location preference

### Each Job Listing Includes:

1. **Job ID**: `JOB-001`, `JOB-002`, etc.
2. **Job Title**: The role name (e.g., "Java Developer", "SpringBoot Engineer")
3. **Company Name**: Hiring company
4. **Location**: City or Remote
5. **Source**: Indeed, Naukri, or LinkedIn
6. **Apply Now Button**: Clickable button with direct link to apply

### Visual Format

Each job will appear in a clean card format:
- Light gray background
- Blue left border
- Professional styling
- Easy to read and click
